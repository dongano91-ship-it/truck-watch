# dealwatch — выгодные предложения на маркетплейсах и Авито

Следит за ценами на Wildberries, Ozon, Авито (и опционально Яндекс Маркет,
Мегамаркет), считает медиану и присылает в Telegram/MAX те предложения,
что дешевле обычной цены на заданный процент.

Работает через **ваш установленный Chrome**: сайты проверяют TLS-отпечаток и
выполняют JS-проверки, поэтому обычные HTTP-запросы они блокируют (403/429),
а настоящий браузер — нет.

```
config.json  →  Chrome (поиск по площадкам)  →  сбор предложений
                                                        ↓
                                    медиана по каждой площадке
                                                        ↓
                              цена ниже медианы на N%  →  Telegram / MAX
```

## Быстрый старт

1. **Тест площадок** — двойной клик `ПРОВЕРКА.bat`.
   Покажет, какая площадка сколько предложений отдала. Если какая-то в СБОЕ —
   см. «Если площадка не отвечает».
2. **Уведомления.** В Telegram: [@BotFather](https://t.me/BotFather) → `/newbot` →
   токен. Напишите боту любое сообщение, узнайте `chat_id`:
   ```
   python ..\get_chat_id.py <ТОКЕН>
   ```
   Впишите в `config.json` → `notify.telegram`.
3. **Свои товары** — раздел `watches` (см. ниже).
4. **Боевой запуск** — двойной клик `ЗАПУСК.bat`. Окно оставьте открытым
   (свернуть можно), остановка — `Ctrl+C`.
5. Проверка, что всё собралось, без ожидания: `ОДИН-ПРОХОД.bat`.

Требуется Python 3.9+ и установленный Google Chrome (или Edge).
Установка пакетов **не нужна** — только стандартная библиотека.

## Свои товары: раздел watches

```json
{
  "id": "iphone15-128",
  "name": "iPhone 15 128 ГБ",
  "query": "iphone 15 128",
  "platforms": ["wb", "ozon", "avito"],
  "must_exclude": ["чехол", "плёнка", "стекло", "кабель"],
  "min_price": 20000,
  "max_price": 150000,
  "threshold_percent": 20,
  "min_offers": 5
}
```

| Поле | Смысл |
|---|---|
| `query` | поисковый запрос на площадке |
| `queries` | другое имя запроса для конкретной площадки: `{"avito": "iphone 15"}` |
| `platforms` | где искать: `wb`, `ozon`, `ym`, `avito`, `mm` |
| `must_exclude` | слова, при которых предложение отбрасывается (чехлы, б/у и т. п.) |
| `must_include` | слова, которые обязаны быть в названии (если заданы — авто-сверка отключается) |
| `min_price` / `max_price` | отсечка мусора и других моделей |
| `threshold_percent` | на сколько процентов дешевле медианы считать «выгодным» |
| `min_offers` | минимум предложений для расчёта медианы (иначе «мало данных») |
| `max_alerts` | сколько уведомлений максимум за один проход |

**Авто-сверка с запросом.** Если `must_include` пуст, инструмент сам требует,
чтобы в названии были все цифры запроса (`15`, `128`) и большинство слов
(`iphone`). Без этого в медиану попадают Pro Max и аксессуары.

**Медиана считается внутри площадки.** Это важно: б/у Авито и новый товар на WB —
разные рынки. Если сравнивать их напрямую, все объявления Авито выглядят
«сделками». Для поиска арбитража (купить на Авито — продать на WB) поставьте
`"median_mode": "global"` в `rules` или в конкретном товаре.

## Площадки и селекторы

Всё в разделе `platforms`. Если площадка поменяла вёрстку — правится только
`config.json`, код трогать не нужно.

```json
{
  "key": "wb",
  "name": "Wildberries",
  "enabled": true,
  "url": "https://www.wildberries.ru/catalog/0/search.aspx?search={q}",
  "warmup": "https://www.wildberries.ru/",
  "mode": "anchors",
  "selector": "a[href*=\"/detail.aspx\"]",
  "id_re": "/catalog/(\\d+)/detail",
  "settle": 5
}
```

- `mode: "anchors"` — ссылки на товар, цена ищется рядом с ссылкой.
- `mode: "cards"` — карточки: `selector` — карточка, `link_sel` — ссылка внутри,
  `title_sel` — название, `price_sel_attr` — откуда взять цену из атрибута.
- `settle` — сколько секунд ждать отрисовки после загрузки.
- `warmup` — страница, которую надо открыть один раз перед поиском
  (Авито и Ozon блокируют первый заход в новой сессии).
- `attempts` — сколько раз повторять при пустой выдаче/капче.

## Авито: два способа

**1. Через браузер** (включён по умолчанию). Работает без логина, но Авито
иногда показывает «Доступ ограничен: проблема с IP» — тогда помогает `warmup`
и повтор, а в тяжёлом случае: откройте Авито в запущенном окне Chrome вручную,
пройдите проверку и запустите `ПРОВЕРКА.bat` снова.

**2. Через почту** (надёжнее и легальнее). Авито сам присылает письма о новых
объявлениях по сохранённому поиску:
1. На Авито подпишитесь на поиск (звёздочка) и включите уведомления на e-mail.
2. В `config.json` → `avito_mail`: `enabled: true`, `imap_host` (`imap.mail.ru`,
   `imap.yandex.ru`, `imap.gmail.com`), логин и **пароль приложения**
   (обычный пароль не подойдёт, если включена двухфакторка).
3. Запускайте как обычно — письма будут попадать в общий расчёт.

### Про «автобронирование» — честно

Автоматической брони на Авито **не существует**: бронь — это договорённость
с продавцом в переписке. Технически «автобронь» возможна только автологином
в ваш аккаунт и автоотправкой сообщений. Это прямо нарушает правила Авито,
ловится антиботом, и аккаунт блокируют — вместе с перепиской и историей.

Что сделано вместо этого — максимально быстрый ручной отклик:

```
python dealwatch.py --respond "https://www.avito.ru/.../item_1234567890"
```

Открывает объявление, нажимает «Написать», вставляет заранее заготовленный
текст (шаблон `respond_template` в `config.json`) в поле сообщения —
**но не отправляет**. Отправку подтверждаете вы, одним нажатием.
Так вы отвечаете за 2–3 секунды после уведомления, а аккаунт остаётся живым.

Уведомление приходит со ссылкой — в Telegram её можно открыть сразу с телефона.

## Команды

```
ПРОВЕРКА.bat                       какие площадки отвечают прямо сейчас
ОДИН-ПРОХОД.bat                    один проход, отчёт в консоль, без ожидания
ЗАПУСК.bat                         цикл с уведомлениями
python dealwatch.py --watch ID     только один товар
python dealwatch.py --test-notify  проверить Telegram/MAX
python dealwatch.py --respond URL  подготовить сообщение продавцу
```

Отчёт, история цен и отметки об отправленном — в `state.json`,
журнал — в `dealwatch.log`.

## Ограничения

- **Антибот.** Ozon и Авито иногда отдают капчу. Лечится повтором, прогревом,
  а в упорном случае — ручным проходом капчи в открытом окне Chrome: профиль
  `.chrome-profile` сохраняет куки между запусками.
- **Яндекс Маркет** стабильно отдаёт капчу автоматизированному браузеру,
  поэтому выключен. Включайте, если у вас он открывается без проверки.
- **Названия товаров** могут приходить обрезанными — на расчёт медианы это
  влияет слабо, но фильтры `must_exclude` стоит задавать.
- **Правила площадок.** Сбор открытых страниц — серая зона; авторизацию,
  переписку и оформление заказов инструмент не автоматизирует намеренно.
- **Не парсите слишком часто.** Интервал по умолчанию 15 минут
  (`poll_seconds: 900`). Чаще — выше шанс капчи и блокировки IP.

## Если площадка не отвечает

1. `ПРОВЕРКА.bat` — покажет тип проблемы (капча / пустая страница / нет предложений).
2. Откройте эту площадку в окне Chrome, которое запустил инструмент
   (профиль `.chrome-profile`), пройдите проверку.
3. Если «предложений не найдено» — изменилась вёрстка: откройте страницу поиска
   в Chrome, `F12` → проверьте селектор из `config.json` (например
   `a[href*="/detail.aspx"]`) и поправьте его.
