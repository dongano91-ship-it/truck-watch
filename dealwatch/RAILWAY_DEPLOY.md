# === Бот 2: DealWatch ===
# Мониторинг цен на маркетплейсах (WB, Ozon, Avito, Яндекс Маркет)
# Уведомления о выгодных предложениях через Telegram

# Для деплоя на Railway:
# 1. Скопируйте файлы из папки dealwatch/railway/ в корень репозитория
# 2. Обратите внимание: этот проект использует Chrome для скрапинга
#    Вам понадобится сервис с поддержкой браузеров (например, Render with Docker)
#
# Альтернатива: запускайте локально с автозапуском через планировщик задач Windows

# Локальный запуск:
python dealwatch.py --test-notify      # тест уведомлений
python dealwatch.py --once             # один проход проверки
python dealwatch.py                    # постоянный мониторинг
