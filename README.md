# truck-watch — слежение за таблицей отгрузок

Скрипт раз в минуту читает Google-таблицу и присылает сообщение (в Telegram
или MAX), когда машина **прибыла**, **начала грузиться**, **выехала** или
когда в строке появилась **красная ячейка** (форс-мажор).

Событие отправляется один раз — при переходе. Если ничего не менялось,
сообщений нет.

## Что нужно

- Windows с Python 3.9+ (проверить: `python --version`)
- Таблица, открытая по ссылке: **Настройки доступа → Все, у кого есть ссылка → Просмотр**
- Токен бота — в Telegram или в MAX (в MAX нужна верификация бизнес-профиля)

Ставить ничего не нужно: только стандартная библиотека, никаких `pip install`.

## Шаг 1. Куда присылать уведомления

Каналы независимы, можно включить оба сразу.

### Telegram (без верификации, 2 минуты)

1. В Telegram откройте [@BotFather](https://t.me/BotFather) → `/newbot` →
   придумайте имя → получите токен вида `123456789:AAE...`.
2. Напишите своему боту любое сообщение (иначе он не сможет вам писать).
3. Узнайте `chat_id`:

   ```
   python get_chat_id.py <ТОКЕН>
   ```

   Скрипт сам поймёт, что это Telegram (в токене есть двоеточие), и покажет
   `chat_id`.

4. Впишите в `config.json`:

   ```json
   "telegram": { "token": "123456789:AAE...", "chat_id": "987654321" }
   ```

### MAX (нужна верификация)

Подключение к платформе MAX открыто только юрлицам, ИП и самозанятым —
резидентам РФ; физлицам верификация недоступна.

1. [business.max.ru/self](https://business.max.ru/self) → профиль → верификация
   через Госуслуги (или T-Business ID / Alfa ID в веб-версии).
2. **Чат-боты** → создать бота → **«⋮» → «Настройки»** → скопировать токен.
3. `python get_chat_id.py <ТОКЕН>` → напишите боту → получите `chat_id`.
4. В `config.json`:

   ```json
   "max": { "token": "ваш_токен", "chat_id": "123456789" }
   ```

### Проверка связи

```
python watcher.py --test-notify
```

Сообщение уйдёт во все настроенные каналы. Если ни один не настроен, текст
попадёт только в лог.

### Как подключить других людей

Два способа, работают одновременно.

**1. Группа (проще всего).** Создайте группу в Telegram, добавьте туда бота
и напишите в группе любое сообщение. Бот подпишется на группу — и все
участники начнут получать уведомления. Ничего настраивать не нужно.

**2. Личная подписка.** Отправьте человеку ссылку на бота
(`https://t.me/ваш_бот`) — он нажимает «Запустить», и с этого момента
получает уведомления лично. Список копится автоматически:

```
python watcher.py --subscribers          # кто подписан
python watcher.py --unsubscribe 12345    # убрать
```

Отписаться можно и из чата: написать боту `/stop`.

> **Дубли не появятся.** Если человек и в группе, и написал боту лично,
> он получит только одну копию — программа проверяет членство в группе
> (через `getChatMember`, с кэшем на час).

> **Бот должен быть запущен**, чтобы ловить новых подписчиков: слушатель
> работает в фоне того же процесса, что и слежение за таблицей.

Отключается это флагом `"share": true` в блоке `telegram` файла
`config.json` (поставьте `false` — останется только группа).

> **Про сертификаты.** API MAX работает на сертификате Минцифры, которого нет
> в стандартном наборе Windows/Python. Поэтому в папке `certs/` лежат
> `russian_trusted_root_ca.crt` и `russian_trusted_sub_ca.crt` — скрипт
> подхватывает их автоматически. Удалять папку нельзя, иначе будет ошибка
> `CERTIFICATE_VERIFY_FAILED`. Крайняя мера — `"insecure_tls": true` в
> настройках MAX (отключает проверку, использовать не рекомендуется).

## Шаг 2. Настройка фильтра

В `config.json`:

```json
"cities": ["Набережные Челны"],
"plates": ["629", "606"],
"filter_mode": "all"
```

- `cities` — подстроки названий городов (без учёта регистра);
- `plates` — номера машин из колонки **«Номер Т/С»** (внутренние номера: 629, 606, 826/064);
- `filter_mode`:
  - `"all"` — нужен **и** город, **и** номер из списка (по умолчанию);
  - `"any"` — достаточно совпадения по одному условию.

Пустой список означает «не фильтровать по этому признаку». Если пусты оба —
уведомления по всем строкам таблицы.

### Как добавить машину

Двойной клик по **3-ДОБАВИТЬ-МАШИНУ.bat** — откроется список и запрос номера.
Можно ввести несколько через пробел: `629 606 317`. Чтобы удалить — с минусом:
`-629`.

То же самое из командной строки:

```
python watcher.py --add-plate 629 606
python watcher.py --remove-plate 629
python watcher.py --plates          # показать текущий список
python watcher.py --list            # строки в городе, ✔ = ваша машина
```

Запущенную программу перезапускать не нужно: `config.json` перечитывается
перед каждым опросом, новый номер заработает в течение минуты.

> **Важно про «прибыла».** Номер появляется в таблице в момент прибытия.
> Пока номера нет, строка не считается вашей — поэтому уведомление «прибыла»
> придёт ровно тогда, когда номер впишут. Это и есть нужный сигнал.

## Шаг 3. Калибровка цветов

Таблица должна отдавать цвета — а они видны только в xlsx, поэтому скрипт
скачивает именно xlsx. Сначала посмотрите, что он видит:

```
python watcher.py --calibrate
```

Откроется отчёт `colors_report.txt`: колонка, цвет, к какому классу
(green / yellow / red) он отнесён и примеры значений. Если какой-то цвет
попал не в тот класс — подкрутите пороги в `config.json` → `colors`.

Полезные поля:

| поле | смысл |
|---|---|
| `green_hue` / `yellow_hue` / `red_hue` | диапазоны оттенков (0–1), в которые попадает цвет |
| `min_saturation` | ниже этого значения цвет считается бледным и игнорируется |
| `status_exclude` | колонки, чей цвет **не** определяет статус строки |
| `red_exclude` | колонки, чей цвет **не** считается форс-мажором |

Разделение важное: в колонке «Сортировка» цвет означает ответственного
(Батыр — зелёный, Мухаммет — красный), а не состояние машины. Поэтому она
попадает в оба списка исключений — иначе каждый второй ряд был бы «форс-мажором».

## Шаг 4. Запуск

```
python watcher.py            # работать постоянно
python watcher.py --once     # один цикл, для проверки
python watcher.py --list     # показать мои строки и их статусы
```

Остановить — `Ctrl+C`. Лог пишется в `watcher.log`, текущее состояние — в
`state.json` (удалить/сбросить: `--reset`).

## Автозапуск при включении компьютера

Планировщик задач → Создать задачу:

- **Триггер**: «При входе в систему»
- **Действие**: запуск программы `pythonw.exe`, аргументы `watcher.py`,
  рабочая папка — папка с проектом.

Или одной командой в PowerShell (от своего имени):

```powershell
schtasks /create /tn "truck-watch" /tr "pythonw.exe \"$PWD\watcher.py\"" /sc onlogon /rl highest
```

`pythonw.exe` запускает без чёрного окна консоли.

## Как определяются статусы

Настроено под вашу таблицу (проверено на живом листе, 62 строки):

| Статус | Признак |
|---|---|
| `arrived` (прибыла) | в колонке «Номер Т/С» появился номер (внутренний номер машины: 629, 606, 826/064) |
| `loading` (грузится) | блок колонок Навигация…Номер Т/С залит зелёным |
| `departed` (выехала) | тот же блок залит жёлтым |
| `problem` (форс-мажор) | красная ячейка вне «Сортировки» («Срыв авто», «не приехал», «Завис отбор») |

Статус может только «расти»: planned → arrived → loading → departed.
Если машина за один цикл прошла два этапа, придёт одно сообщение:

```
🚛 Машина: прибыла → начала грузиться
Москва день в день · 05.11.2026 02:30 · Т/С 606 · МЛ 00051150 · объём 108.4
```

Жёлтый цвет отличается от оранжевого («по звонку»), поэтому диапазон
оттенка сужен до `[0.13, 0.19]` — иначе оранжевые пометки считались бы
отправкой.

## Если что-то не работает

| Симптом | Причина |
|---|---|
| «Пришёл не xlsx» | таблица не открыта по ссылке — включите доступ «Просмотр» |
| «Не нашёл заголовок ГОРОД» | изменилась структура листа — проверьте колонки |
| «Каналы не настроены» | в `config.json` пустые `token`/`chat_id` |
| `MAX ответил 401` / `Telegram ответил 401` | неверный токен |
| `MAX ответил 400` / `Telegram ответил 400` | неверный `chat_id` |
| Telegram: `chat not found` | боту не написали ни одного сообщения — напишите первым |
| Цвета не распознаются | прогоните `--calibrate` и подкрутите пороги |
| `CERTIFICATE_VERIFY_FAILED` | потерялась папка `certs/` с сертификатом Минцифры (нужна только для MAX) |

## Ограничения, о которых стоит знать

- **Задержка до минуты** — опрос раз в 60 секунд (`poll_seconds`).
- **Компьютер должен быть включён.** Если нужен режим 24/7 — тот же код
  можно повесить на бесплатный хостинг или переписать под Google Apps Script
  (тогда работает внутри таблицы, но нужны права редактора).
- **Нагрузка на Google**: полный xlsx раз в минуту — нормально для одной
  таблицы, но не стоит ставить интервал меньше 30 секунд.
- **Цвет — не текст.** Если кто-то в таблице закрасит ячейку просто «чтобы
  выделить», трекер воспримет это как событие.
